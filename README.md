# 星穹弈境 · Astral Chess Arena

> **棋盘自走棋** —— NodeJS + SQLite 后端，浏览器前端。
> 把国际象棋的走法与「将军/升变」搬进自走棋的商店—养成—战斗循环。

本项目由原版单文件浏览器游戏《星穹弈境》（`legacy/星穹弈境.html`）重写而来：
玩法内核（暴击连击链、职业分工、成长上限）保留，架构、持久化与战斗结算全部重做。

---

## 快速开始

```bash
cd astral-chess-arena
npm run dev
```

浏览器会自动打开 `http://127.0.0.1:5180/`。
**不需要 `npm install`** —— 本项目零运行时依赖，只用 Node 内置的
`node:http` 与 `node:sqlite`。

> 环境要求：**Node ≥ 22.5**（推荐 24）。`node:sqlite` 是内置实验特性，
> 启动脚本已用 `--disable-warning=ExperimentalWarning` 静音警告。
> Windows 用户如果 `node` 不在 PATH 里，npm 会自己找到。

其它命令：

```bash
npm test                  # 单元测试（node:test，43 条）
node tools/smoke-api.mjs  # 端到端接口冒烟测试（需先 npm run dev）
node tools/balance-sim.mjs # 平衡性模拟：跑批战斗看各章节胜率
npm run doc               # 从会话记录生成提交用的 Word 文档
```

## 玩法速览

```
准备阶段                          战斗阶段（自动）              结算
┌────────────────┐              ┌────────────────┐        ┌──────────┐
│ 商店：买棋子/刷新│              │ 敌方布阵       │        │ 金币 +   │
│ 布阵：点棋子→点格│  ────────▶  │ 轮流走位+攻击   │ ─────▶ │ 连胜奖励 │
│ 养成：训练/升阶/突破│            │ 暴击/连击/处决  │        │ 章节 +1  │
└────────────────┘              └────────────────┘        └──────────┘
```

- **棋盘**：8×8，己方在下 4 排，敌方在上 4 排。
- **棋子**：兵 ♟ / 马 ♞ / 主教 ♝ / 车 ♜ / 后 ♛ / 王 ♚，**按国际象棋走法移动与攻击**。
- **传统机制**：兵到底线**升变**、王被攻击进入**将军**、王被击落即**将死**、
  **王车易位**、**吃过路兵**、马的**蹩马腿**。
- **自走棋机制**：商店 5 槽 + 刷新、回合经济（基础收入 / 连胜 / **利息**）、
  4 职业**羁绊**（2/4/6 件三档）、每人 3 件**装备**、**训练 / 升阶 / 突破 / 附魔**。
- **数值取向**：割草膨胀。暴击倍率在 [1.0,1.5) 波动，波动 >1.2 触发**无界连击链**；
  叠加**破防**（连续命中累积满值则目标防御归零 3 回合）、**护盾**、
  **最终伤害倍率**、**大招倍率**，最后目标残血（<15%）直接**处决**。
- **打击感**：屏幕震动（按伤害量级分 4 档）、命中顿帧、伤害飘字（字号随量级分级）、
  连击横幅、破防标记、升变光柱、处决十字斩、将死全屏黑闪，外加程序化 WebAudio 音效。

| 来源 | 借鉴了什么 |
|---|---|
| **国际象棋** | 六种棋子的走法与阻挡规则、蹩马腿、兵升变、将军/将死、王车易位、吃过路兵、终局和棋 |
| **《云顶之弈》(TFT)** | 商店与刷新、回合经济（基础收入 / 连胜连败 / **存款利息**）、**羁绊**（同职业 2/4/6 件三档）、星级与棋子池、章节式难度推进 |
| **《Dota 2》自走棋 ( autochess)** | **棋盘自走棋**的形态本身：棋子上场占位、前后排站位、装备栏、「自动战斗 + 前后各一半回合」的节奏 |
| **《炉石传说》** | 卡牌附魔（`+ / ×` 两种操作、10 种属性）、卡牌稀有度、随机强化 |
| **《杀戮尖塔》(Slay the Spire)** | 单局构筑思路：每回合做「买 / 刷 / 强化」的有限决策，章节式推进 |
| **原版《星穹弈境》**（本仓库 `legacy/`） | **暴击连击链**、暴击倍率波动、职业分工（影刃/奥术师/圣疗者/铁卫）、等级成长上限表、棋盘自走棋的战前布阵与回合循环 |

## 数据模型

SQLite，10 张表，静态内容与动态数据分表，**不把整个游戏状态塞进一个 JSON 字段**：

| 表 | 作用 |
|---|---|
| `professions` / `synergies` | 职业与羁绊档位 |
| `piece_templates` | 棋子模板（图鉴、商店池） |
| `equipments` / `cards` | 装备与卡牌池 |
| `saves` | 存档槽：资源、章节、回合、连胜连败、RNG 种子与状态 |
| `save_heroes` | 存档内的棋子（属性、站位、装备、突破加成） |
| `save_cards` | 存档内的卡牌 |
| `save_items` | 存档内的装备背包 |
| `shop_slots` | 商店 5 个槽位（每回合刷新 + 售出标记） |
| `battles` | 战斗记录（含完整事件流，可回看） |

所有写操作都在**同一个事务**里落盘 —— 买了东西、升级了、突破了就一定存得住，
不存在「花了钱没保存」的情况。

## 已修复的原版问题

移植过程中修掉了原版 20 个已确认的 bug，完整对照表见 `SPEC.md` 的
「原版 bug 修复对照表」。几个代表性的：

| 原版问题 | 现在 |
|---|---|
| 「最终伤害倍数」卡牌实际加的是大招倍率 | 独立的 `finalDamageMult`，真的参与结算 |
| 初始棋子攻击力超过 1 级上限，第一次升级就被悄悄砍掉 | 初始值 = 模板值 × 等级系数，永远在上限内 |
| 撞到部分属性上限仍然收金币、仍然涨成本指数 | 撞上限直接禁用并说明，不吞资源 |
| 生命卡只加当前血不加上限，血条会超过 100% | 生命类卡同时改 `maxHp` 与 `hp` |
| 闪避判定在连击链之后，日志会打出不存在的暴击 | 整条链一起判定，先判后打日志 |
| 取消锻造弹窗会吞掉金丹 | 资源扣减放在确认动作里，取消零损耗 |
| 升阶取所有属性的**平均值**（实测只有 +24% DPS、−35% 血池） | 「取大 + 小的 50%」 |
| 100 回合超时判**负** | 超时判平局 |
| 布阵系统整条链路是死代码 | 布阵 UI 与 API 都实装 |
| 只有三处 autosave，其它操作不落盘 | 所有写操作同事务落盘 |
| 敌方只缩放血和攻击，等级/星级/装备/羁绊都不长 | 敌方等级、星级、装备、羁绊一起成长 |
| 没有种子随机数，战斗不可复现 | xorshift128+，种子与状态入库 |
| `innerHTML` 全量重绘把正在播的动画冲掉 | 服务端产出事件流 → 前端增量渲染 |
| 敌方阶段是友方阶段 60 行的复制粘贴 | 一个 `runPhase(side)`，两侧共用 |
| 声称「按速度决定行动顺序」但根本没有 speed 字段 | 真的有 speed，进入行动排序 |
